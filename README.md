# Расписание БГМУ — PWA

Минимальное офлайн-приложение расписания для телефона.

## Что умеет

- работает как сайт;
- устанавливается на iPhone через Safari → Поделиться → На экран «Домой»;
- работает офлайн после первого успешного открытия;
- показывает сегодняшний день;
- автоматически вычисляет день недели;
- кнопки предыдущего/следующего дня;
- свайп влево/вправо по расписанию;
- название предмета + время;
- расписание хранится локально в `data/schedule.json`.

## Как заменить расписание

Откройте:

`data/schedule.json`

Формат:

```json
{
  "group": "8101",
  "semester": "2026/2027",
  "lessons": [
    {
      "date": "2026-09-01",
      "start": "08:35",
      "end": "10:00",
      "subject": "БЖЧ (ОТ)"
    }
  ]
}
```

Дата должна быть в формате `YYYY-MM-DD`.

## Важно для iPhone

PWA и Service Worker требуют HTTPS или localhost. Просто открыть `index.html` как локальный файл недостаточно для полноценного офлайн-режима.

Проще всего разместить папку на GitHub Pages, Cloudflare Pages, Netlify или другом статическом HTTPS-хостинге.

После установки на экран «Домой» приложение открывается без адресной строки браузера.
